User-defined functions

Fin.Variance

Actual minus comparison; blank only when both sides are blank.

( actual : NUMERIC, comparison : NUMERIC ) => IF ( NOT ISBLANK ( actual ) || NOT ISBLANK ( comparison ), actual - comparison )

Fin.VariancePct

Variance as a share of the absolute comparison, so a cost line reads the same way as income.

( variance : NUMERIC, comparison : NUMERIC ) => DIVIDE ( variance, ABS ( comparison ) )

Fin.VarianceColor

Teal when favourable, orange when not, for conditional formatting.

( variance : NUMERIC ) => IF ( variance >= 0, "#0F766E", "#C2410C" )

Fin.OnLine

Evaluates a measure on one P&L line (subtotals reach every account under them).

( value : SCALAR NUMERIC EXPR, lineId : STRING ) => CALCULATE ( value, 'P&L Line'[Line ID] = lineId )

Fin.PriorYear

A measure one year back on the calendar passed in.

( value : SCALAR NUMERIC EXPR, cal : CALENDARREF ) => CALCULATE ( value, DATEADD ( cal, -1, YEAR ) )

Fin.Millions

An amount as short text in millions, e.g. $13.8m.

( amount : NUMERIC ) => FORMAT ( amount / 1e6, "$#,0.0" ) & "m"

Svg.VarianceBar

An inline SVG bar centred on zero: right and teal when favourable, left and orange when not.

( variance : NUMERIC, maxAbs : NUMERIC ) =>
    VAR _w = ROUND ( DIVIDE ( ABS ( variance ), maxAbs ) * 58, 1 )
    VAR _x = IF ( variance >= 0, 60, 60 - _w )
    VAR _c = IF ( variance >= 0, "%230F766E", "%23C2410C" )
    RETURN
        IF ( NOT ISBLANK ( variance ),
            "data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='120' height='16'>"
                & "<rect x='" & _x & "' y='3' width='" & _w & "' height='10' rx='2' fill='" & _c & "'/>"
                & "<line x1='60' y1='0' x2='60' y2='16' stroke='%238C959F'/></svg>" )

Headline Insight

One-sentence dynamic insight for the overview page.

VAR _v = [Operating Profit Variance]
VAR _s = [Net Sales Variance]
VAR _o = [Operating Expenses Variance]
VAR _cmp = LOWER ( SELECTEDVALUE ( 'Compare To'[Compare To], "Budget" ) )
RETURN
    "Operating profit " & Fin.Millions ( [Operating Profit] )
        & ", " & Fin.Millions ( ABS ( _v ) ) & IF ( _v >= 0, " ahead of ", " behind " ) & _cmp & ". "
        & "Net sales " & IF ( _s >= 0, "beat it by ", "missed it by " ) & Fin.Millions ( ABS ( _s ) )
        & ", operating expenses " & IF ( _o >= 0, "came in " & Fin.Millions ( _o ) & " under", "overran by " & Fin.Millions ( - _o ) ) & "."
