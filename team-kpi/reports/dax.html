User-defined functions

Kpi.Rate

Part ÷ whole; blank when the whole is empty.

( part : NUMERIC, whole : NUMERIC ) => DIVIDE ( part, whole )

Kpi.Status

On track from 90%, at risk from 75%, off track below that.

( rate : NUMERIC ) =>
    SWITCH ( TRUE (),
        ISBLANK ( rate ), BLANK (),
        rate >= 0.9, "On track",
        rate >= 0.75, "At risk",
        "Off track" )

Kpi.StatusColor

Hex colour for a status, for conditional formatting.

( status : STRING ) => SWITCH ( status, "On track", "#1B7F4B", "At risk", "#A35F00", "Off track", "#B42318", "#8C959F" )

Kpi.ShareOf

A measure as a share of the same measure with the filters on one table or column removed.

( value : SCALAR NUMERIC EXPR, scope : ANYREF ) => DIVIDE ( value, CALCULATE ( value, REMOVEFILTERS ( scope ) ) )

Kpi.PriorYear

A measure one year back on the calendar passed in.

( value : SCALAR NUMERIC EXPR, cal : CALENDARREF ) => CALCULATE ( value, DATEADD ( cal, -1, YEAR ) )

Kpi.PriorWeek

A measure one week back on the calendar passed in.

( value : SCALAR NUMERIC EXPR, cal : CALENDARREF ) => CALCULATE ( value, DATEADD ( cal, -1, WEEK ) )

Sla.Within

True when the time taken is within the target scaled by the what-if SLA scale.

( taken : NUMERIC, target : NUMERIC, scale : NUMERIC ) => taken <= target * scale

Flow.Percentile

The k-th percentile of a duration column in the current filter (0.85 = 85th).

( days : ANYREF, k : NUMERIC ) => PERCENTILEX.INC ( FILTER ( VALUES ( days ), NOT ISBLANK ( days ) ), days, k )
