Stock.SafetyStock

Safety stock for one line: z × √(lead days × daily SD² + daily demand² × lead-time SD²).

( z : NUMERIC, demand : NUMERIC, lead : NUMERIC, demandSd : NUMERIC, leadSd : NUMERIC ) =>
    z * SQRT ( lead * demandSd ^ 2 + demand ^ 2 * leadSd ^ 2 )

Lines To Order

Lines at or below their reorder point.

#,0
VAR _z = [Service Z]
VAR _r = [Review Days Selected]
RETURN
    SUMX (
        Stock,
        VAR _d = Stock[Daily Forecast]
        VAR _l = Stock[Lead Days]
        VAR _ss = Stock.SafetyStock ( _z, _d, _l, Stock[Daily SD], Stock[Lead SD] )
        VAR _due = _d > 0 && Stock[End Units] <= _d * _l + _ss
        RETURN IF ( _due, 1 )
    )

Units To Order
