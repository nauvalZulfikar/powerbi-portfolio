F1.Rate

( part : NUMERIC, whole : NUMERIC ) => DIVIDE ( part, whole )

A value as a share of a total. VAL parameters: both are computed by the caller, then divided.

F1.PrevSeason

A measure one season back. EXPR parameter: re-evaluated after DATEADD shifts the dates.

( value : SCALAR NUMERIC EXPR ) => CALCULATE ( value, DATEADD ( 'Calendar'[Date], -1, YEAR ), REMOVEFILTERS ( Season ) )

F1.SeasonToDate

Any measure from the season's first race to the date in context, on the calendar passed in (typed CALENDARREF).

( value : SCALAR NUMERIC EXPR, cal : CALENDARREF ) => CALCULATE ( value, DATESYTD ( cal ) )
