User-defined functions

Kpi.Rate

Part ÷ whole; blank when the whole is empty.

( part : NUMERIC, whole : NUMERIC ) => DIVIDE ( part, whole )

Kpi.ShareOf

A measure as a share of the same measure with the filters on one column or table removed.

( value : SCALAR NUMERIC EXPR, scope : ANYREF ) => DIVIDE ( value, CALCULATE ( value, REMOVEFILTERS ( scope ) ) )

Kpi.Lift

Win rate inside a segment ÷ win rate of everything else in the visual (1.0 = no difference).

( won : NUMERIC, closed : NUMERIC, allWon : NUMERIC, allClosed : NUMERIC ) =>
    DIVIDE ( DIVIDE ( won, closed ), DIVIDE ( allWon - won, allClosed - closed ) )

Kpi.PriorMonth

A measure one month back on the calendar passed in.

( value : SCALAR NUMERIC EXPR, cal : CALENDARREF ) => CALCULATE ( value, DATEADD ( cal, -1, MONTH ) )

Kpi.PriorYear

A measure one year back on the calendar passed in.

( value : SCALAR NUMERIC EXPR, cal : CALENDARREF ) => CALCULATE ( value, DATEADD ( cal, -1, YEAR ) )

Fmt.Money

An amount as text in millions, e.g. $3.5m.

( amount : NUMERIC ) => FORMAT ( amount / 1e6, "$#,0.0" ) & "m"
