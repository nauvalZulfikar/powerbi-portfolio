LC.MaturedOnly

Evaluates a measure on matured, resolved loans only: the methodology rule behind every lifetime rate, in one place. EXPR: the measure is evaluated inside the CALCULATE, after the filter is applied.

( m : SCALAR NUMERIC EXPR ) =>
    CALCULATE ( m, Loans[Is Resolved] = TRUE (), Loans[Is Matured] = TRUE () )

LC.SafeRate

Part ÷ whole, blank when the whole is empty. VAL: both numbers are computed once, in the caller's filter context.

( num : SCALAR NUMERIC VAL, den : SCALAR NUMERIC VAL ) => DIVIDE ( num, den )

LC.VsPortfolio

A measure minus the same measure over everything selected on the page (percentage points for rates). MEASUREREF: the measure itself is passed, so it can be re-evaluated under ALLSELECTED.

( m : MEASUREREF ) => m - CALCULATE ( m, ALLSELECTED () )

Stressed Expected Loss

Live-book expected loss with PD × multiplier (capped at 100%) and LGD + shock (kept within 0–100%).

$#,0
VAR _m = [PD Multiplier Value]
VAR _s = [LGD Shock Value]
RETURN
    CALCULATE (
        SUMX ( Loans,
            Loans[Outstanding Principal Amt] * MIN ( 1, Loans[PD] * _m )
                * MAX ( 0, MIN ( 1, RELATED ( 'Grade LGD'[Grade LGD Rate] ) + _s ) ) ),
        Loans[Outcome] IN { "Current", "Delinquent" }
    )

Mix Effect

Change in default rate from the latest matured vintage year in the filter vs the year before, caused by the grade mix: Σ (weight now − weight before) × rate before. Whole issue years (the year slicer only picks the year).

+0.00%;-0.00%;0.00%
VAR _y = CALCULATE ( MAX ( Loans[Vintage Year] ), Loans[Is Matured] = TRUE () )
VAR _n1 = CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y )
VAR _n0 = CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y - 1 )
RETURN
    IF ( _n0 > 0,
        SUMX ( VALUES ( Grade[Grade] ),
            VAR _w1 = DIVIDE ( CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y ), _n1 )
            VAR _w0 = DIVIDE ( CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y - 1 ), _n0 )
            VAR _r1 = DIVIDE ( CALCULATE ( [Matured Defaults], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y ), CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y ) )
            VAR _r0 = DIVIDE ( CALCULATE ( [Matured Defaults], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y - 1 ), CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y - 1 ) )
            RETURN ( _w1 - _w0 ) * _r0
        )
    )

+0.00%;-0.00%;0.00%

VAR _n0 = CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y - 1 )
RETURN
    IF ( _n0 > 0,
        SUMX ( VALUES ( Grade[Grade] ),
            VAR _w1 = DIVIDE ( CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y ), _n1 )
            VAR _w0 = DIVIDE ( CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y - 1 ), _n0 )
            VAR _r1 = DIVIDE ( CALCULATE ( [Matured Defaults], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y ), CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y ) )
            VAR _r0 = DIVIDE ( CALCULATE ( [Matured Defaults], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y - 1 ), CALCULATE ( [Matured Loans], REMOVEFILTERS ( 'Date' ), Loans[Vintage Year] = _y - 1 ) )
            RETURN _w1 * ( _r1 - _r0 )

    )

Funded Trend

Least-squares line through monthly funded amount (LINESTX over the months selected), read at this month.

$#,0
VAR _pts =
    FILTER (
        ADDCOLUMNS ( ALLSELECTED ( 'Date'[Month Start] ),
            "@x", YEAR ( 'Date'[Month Start] ) * 12 + MONTH ( 'Date'[Month Start] ),
            "@y", [Funded Amount] ),
        NOT ISBLANK ( [@y] )
    )
VAR _fit = LINESTX ( _pts, [@y], [@x] )
VAR _d = MAX ( 'Date'[Month Start] )
RETURN
    IF ( NOT ISBLANK ( [Funded Amount] ),
        MAXX ( _fit, [Intercept] ) + MAXX ( _fit, [Slope1] ) * ( YEAR ( _d ) * 12 + MONTH ( _d ) ) )
